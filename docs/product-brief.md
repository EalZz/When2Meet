# When2Meet App 간단 기획서

## 1. 서비스 개요

When2Meet App은 같은 방에 참여한 사용자들이 서로 가능한 날짜와 시간을 공유하고, 2명 이상 가능한 시간이 겹치는 구간을 약속 후보로 확인할 수 있는 Android/iOS 일정 조율 앱입니다.

## 2. 목적

여러 사람이 메시지를 반복해서 주고받지 않아도, 한 방 안에서 가능한 시간을 입력하고 앱이 겹치는 시간을 자동으로 정리해 약속 후보를 빠르게 찾게 하는 것이 목적입니다.

## 3. 주요 사용자 흐름

1. 사용자는 Supabase Auth 기반 회원가입/로그인을 진행합니다.
2. 로그인 후 방을 만들거나 초대 코드를 입력해 기존 방에 참여합니다.
3. 방 안의 캘린더에서 날짜를 선택합니다.
4. 날짜별 타임라인에서 `08:00-23:30` 범위의 시간을 30분 단위로 체크합니다.
5. 앱은 2명 이상이 체크한 날짜 중, 2명 이상이 가능하다고 표시한 시간이 겹치면 후보 시간으로 보여줍니다.
6. 사용자는 후보 시간을 눌러 해당 날짜의 타임라인을 확인하고 약속 시간을 결정합니다.
7. 사용자는 설정 화면에서 프로필, 테마, 로그아웃을 관리합니다.

## 4. 핵심 기능

### 회원가입/로그인

- Supabase Auth를 사용합니다.
- MVP에서는 복잡한 본인인증 없이 간단한 가입 흐름을 제공합니다.
- 사용자 프로필에는 이름, 프로필 사진, 한줄소개를 저장합니다.

### 방 만들기/참여

- 사용자는 새 방을 만들 수 있습니다.
- 방을 만들면 초대 코드가 생성됩니다.
- 다른 사용자는 초대 코드를 입력해 방에 참여합니다.
- MVP에서는 직접 사용자 검색 초대보다 초대 코드 방식을 우선 적용합니다.

### 캘린더

- 방별 월간 캘린더를 보여줍니다.
- 날짜를 누르면 해당 날짜의 30분 단위 타임라인으로 이동합니다.
- 날짜별로 사용자 상태를 요약 표시합니다.
  - 전체 가능: 초록색 원과 사용자명
  - 전체 불가능: 빨간색 원과 사용자명
  - 일부 가능: 노란색 원과 사용자명

### 타임라인 입력

- 하루 표시 범위는 `08:00-23:30`입니다.
- 시간은 30분 단위 슬롯으로 나눕니다.
- 기본 상태는 미체크입니다.
- 미체크는 후보 계산에서 불가능으로 간주합니다.
- 가능은 초록색, 불가능은 빨간색으로 표시합니다.
- 일정 이름은 날짜별 사용자 입력에 1개만 저장합니다.
- 사용자는 자신이 입력한 일정만 수정할 수 있습니다.

### 약속 후보

- 1차 기준: 해당 날짜에 2명 이상이 가능/불가능 여부를 체크해야 합니다.
- 2차 기준: 같은 30분 슬롯에 2명 이상이 가능으로 체크되어야 합니다.
- 조건을 만족한 시간만 후보로 표시합니다.
- 후보를 누르면 해당 날짜의 타임라인으로 이동합니다.

### 이슈/요청 페이지

- 사용자는 앱 안에서 버그나 추가 요청을 보낼 수 있습니다.
- 요청 종류는 버그, 개선 요청, 기능 요청으로 나눕니다.
- 제목, 내용, 관련 방 정보를 함께 저장할 수 있습니다.
- 관리자 화면에서 접수된 요청 목록을 확인하고 상태를 변경할 수 있습니다.

### 설정 화면

- 이름, 프로필 사진, 한줄소개를 수정할 수 있습니다.
- 테마를 시스템 설정, 라이트 모드, 다크 모드 중 선택할 수 있습니다.
- 로그아웃을 할 수 있습니다.

## 5. 디자인 방향

- 기본 인상은 검정색 기반의 세련된 다크 UI로 잡습니다.
- 시스템 설정에 따라 라이트/다크 모드를 자동 전환할 수 있게 합니다.
- 사용자가 설정 화면에서 라이트 모드, 다크 모드, 시스템 설정을 직접 선택할 수 있게 합니다.

## 6. MVP 범위

MVP에는 다음 기능을 포함합니다.

- 회원가입/로그인
- 프로필 편집
- 라이트/다크/시스템 테마 선택
- 로그아웃
- 방 생성
- 초대 코드로 방 참여
- 방별 캘린더
- 날짜별 30분 타임라인
- 가능/불가능 입력
- 날짜별 일정 이름 입력
- 기존 입력 수정
- 2명 이상 가능 시간이 겹치는 후보 표시
- 사용자 이슈/요청 등록 페이지
- 관리자 이슈/요청 목록 및 상태 변경 화면

다음 기능은 후속 버전으로 분리합니다.

- 기기 캘린더 앱 자동 연동
- 푸시 알림
- 방장 권한 세분화
- 사용자 직접 초대
- 반복 일정
- 후보 기준 커스터마이징

## 7. 기술 방향

- 앱: Expo + React Native
- 언어: TypeScript
- 백엔드/DB: Supabase
- 인증: Supabase Auth
- 데이터베이스: PostgreSQL
- 주요 저장 데이터: 사용자 프로필, 방, 방 멤버, 날짜별 일정 이름, 30분 단위 가능 시간, 사용자 이슈

## 8. 성공 기준

- 사용자가 Android/iOS에서 같은 기능을 사용할 수 있습니다.
- 초대 코드만으로 방 참여가 가능합니다.
- 사용자가 `08:00-23:30` 범위에서 30분 단위로 가능/불가능 시간을 입력하고 수정할 수 있습니다.
- 날짜별 일정 이름을 저장할 수 있습니다.
- 2명 이상 가능한 시간이 겹치면 후보로 표시됩니다.
- 사용자가 설정 화면에서 프로필, 테마, 로그아웃을 관리할 수 있습니다.
- 사용자가 앱 안에서 버그나 기능 요청을 보낼 수 있습니다.
- 관리자가 앱 안에서 이슈/요청 상태를 관리할 수 있습니다.
